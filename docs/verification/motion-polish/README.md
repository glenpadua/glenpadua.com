Lake figures are a deterministic scheduling simulation, not a physical-device FPS or CPU measurement. The pose timings are unchanged. Cheered reps are counted at exact boundaries, and delayed callbacks cannot skip an entire recovery. [Raw measurements](measurements.json) record the image sizes and callback counts.

The Beach crop is purely mechanical, generated by `node scripts/prepare-beach-typing-patch.mjs` from the approved `public/assets/world/beach-typing-focused-tap.webp`, then encoded with `node scripts/encode-art.mjs`. The full-quality crop is `art-source/world/beach-typing-tap-crop-v1.webp`; the runtime copy is `public/assets/world/beach-typing-tap-crop-v1.webp`. There is no new generated artwork in this follow-up. Tests verify dimensions, exact alpha preservation and bounded RGB encoding error.

The reveal-script change follows the installed Next 16.3.5 guide, `node_modules/next/dist/docs/01-app/02-guides/preventing-flash-before-hydration.md`. Direct parsing still runs the first-load reveal; client navigation uses the existing effect. The CDN endpoint returned HTTP 200 and the release build fetched all eight article routes successfully.

## Release checks and limits

Final `npm run typecheck`, `npm run lint`, `npm run build -- --webpack` and all **69** `npm run test:diorama` checks passed. The tests include contracts, shoreline masks, sprite alpha cleanup, clocks, fixed geometry, globe motion and built article routes. `git diff --check` passed before committing.

One intermediate build could not resolve the new CDN hostname inside the restricted shell. The public endpoint was verified and the build succeeded with network access; build-dependent tests were rerun against that completed output. A typecheck overlapping generated-type replacement was also rerun after the successful build. These intermediate failures were not treated as successful checks.

Portrait observations use browser emulation, not a physical phone. OS reduced-motion switching and hidden-tab suspension were reviewed through their shared code paths, not forced in the browser. No field Core Web Vitals, screen-reader audit or hosted deployment is claimed.
