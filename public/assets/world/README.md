# World assets

Every website visual asset follows [the shared art style](../../../docs/art-style.md). Read it before creating, selecting, deriving or animating an asset, including article covers. It is the sole style definition and owns the reference set and revision process.

Keep original references and historical provenance manifests. Record source assets, style revision, authorship/generation, dimensions, cropping and review evidence for new or revised assets as specified there. Scene-specific geometry belongs with the scene; article cover assignments live in `features/diorama/articles/covers.ts`.

Existing approved illustrations form the initial baseline. Documentary photographs, screenshots, scans and third-party marks follow the guide's source-preservation treatment. Updating the guide does not automatically update image files; future revision work must inventory and review existing assets too.

Large paintings are served as encoded copies; their approved full-quality files live in [art-source/world](../../../art-source/README.md).
