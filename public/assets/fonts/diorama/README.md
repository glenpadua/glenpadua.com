# Diorama fonts

Selected by Glen on 27 September 2026: Lora headings and italic signature, Nunito Sans text and navigation.

Unmodified variable WOFF2 files from Google Fonts CSS API, downloaded 27 September 2026. Lora normal/italic 400–600; Nunito Sans normal 400–700. Latin and Latin Extended subsets retain their supplied unicode ranges. Font-face declarations are in features/diorama/styles/typography.css. Both families use the included SIL Open Font License.

Sources:
- https://fonts.google.com/specimen/Lora
- https://fonts.google.com/specimen/Nunito+Sans
- https://github.com/google/fonts/tree/main/ofl/lora
- https://github.com/google/fonts/tree/main/ofl/nunitosans
